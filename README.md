## A commercial food delivery landing page showcasing restaurants and services.

Built the fully responsive frontend using a dual-solution approach for key features (Axios/Fetch, Swiper/native scrolling, basicLightbox/native modal).

Implemented form handling and data persistence with localStorage, and integrated iziToast to provide a smooth, user-friendly experience.
